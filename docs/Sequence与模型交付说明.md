# FAN-A01 Sequence 与模型操作台接入说明

本交付目录供生产商开发自己的生产操作台使用。检测型号、测试步骤和判定逻辑已经写入 `FAN-A01.sequence.json`。生产商的软件只需导入该 JSON 文件，并使用同目录的 `FAN-A01.onnx` 执行检测。

Sequence 的创建、修改和重新导出由我方负责，生产商不需要开发 Sequence 设置功能。

## 1. 交付文件

```text
FAN-A01.sequence.json
FAN-A01.onnx
FAN-A01-Deployment-Reference.zh-CN.md
SHA256SUMS.txt
input\IMG_1533.JPG
```

- `FAN-A01.sequence.json`：已经配置好的 FAN-A01 测试序列。
- `FAN-A01.onnx`：该测试序列对应的检测模型。
- `input\IMG_1533.JPG`：供接收方进行一次本地导入与运行验证的代表图，不是生产数据或模型精度证明。
- `SHA256SUMS.txt`：交付文件的 SHA-256 校验值。

## 2. 双方分工

我方负责创建和更新 Sequence、配置检测逻辑、提供对应模型，并在内容变化后重新交付。

生产商负责开发生产操作台，使操作台能够导入我方交付的 Sequence JSON、加载对应模型、绑定文件夹或相机图源、执行检测、显示结果并保存生产日志。

生产商不需要开发 Sequence 设置、ROI 标注、模型库、标签编辑或判定规则编辑功能。

## 3. 导入与运行

1. 保持交付目录中的 JSON、模型和其他文件名称不变。
2. 在生产操作台中选择“导入 Sequence”，然后选择 `FAN-A01.sequence.json`。
3. 操作台读取该 JSON 中的型号、测试步骤和判定逻辑，并加载同目录的 `FAN-A01.onnx`。
4. 将图源绑定到本机图片文件夹或现场相机。
5. 校验通过后按 Sequence 中的步骤和规则执行检测；导入或校验失败时应保留原配置并显示错误。

正式部署时，生产商可将图源绑定到自己的文件夹、相机或现场协议。交付包中的 `input\IMG_1533.JPG` 仅用于首次接入验证。

## 4. 操作台显示要求

- 显示当前型号、测试步骤和最终结果。
- 检测图保留原图、检测框和模型原始英文 Label，不显示置信度，不翻译 Label。
- 检测结果表格按照 Sequence 中的具体判定逻辑显示数量、存在/不存在或其他实测内容，不能统一简化成数量。
- 单项及总结果应有明确的 PASS/FAIL 颜色区分。
- 操作员不需要在操作台中重新配置检测步骤或判定规则。

## 5. 序列号与日志

- 文件夹图源：每张图片的主文件名作为该产品的序列号。
- 相机图源：开始检测时输入序列号，确认后执行一次检测。
- 每次检测完成后保存生产 TXT 和结果图片。
- TXT 列格式：`机台|日期|时间|工站|型号|员工号|序列号|测试结果|图片地址|`。
- PASS 和 FAIL 图片分别保存，文件名包含序列号、时间和结果。

## 6. 接收校验

```powershell
Set-Location '<交付目录>'
Get-ChildItem -File -Recurse | Get-FileHash -Algorithm SHA256
```

计算结果应与 `SHA256SUMS.txt` 一致。交付和复制时请保持整个目录结构。
